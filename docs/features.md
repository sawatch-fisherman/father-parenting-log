# TotoOps 機能一覧

> 本ドキュメントは Laravel 実装前の企画整理段階の資料です。
> 機能の案出しと整理が目的であり、確定仕様ではありません。判断が必要な点は [decisions.md](decisions.md) の「未決事項」に整理しています。

実装フェーズは以下の4段階に分けます。

- **MVP**：最初に作る最小機能。父親の育児ログ・称号・X投稿文・自分の集計に絞る。
- **Phase 2**：他の父親の育児「傾向」を見る集計機能。
- **Phase 3**：PWA 化・通知など、使い勝手の向上。
- **将来案**：AI 要約や NativePHP など、Web 版が形になってから検討。

## フェーズ別サマリ

> 方針：**シンプルな機能から実装する**。外部サービス連携（LINE）や広告は後回し。
> ただし下記「基盤」は機能ではなく土台であり、**後付けは高コスト**なので MVP の設計段階で最初から組み込む。

### 基盤（MVP の DB／設計段階で最初から入れる）

- ID／主キーの形式（**露出するテーブルのみ ULID・他は連番**。[decisions.md](decisions.md) §1.3）
- **ログテーブルとマスタ／ユーザーテーブルの分離**
- **二重送信防止（冪等性）** … ボタン同時押しでも2重登録させない

詳細は [decisions.md](decisions.md) の「設計原則（アーキテクチャ）」を参照。

### MVP（最初に作る）

1. ユーザー登録・ログイン
2. プロフィール登録（ニックネーム：必須／年代・子どもの年齢帯〈末子1つ〉：ともに任意）
3. グローバルナビゲーション（記録・履歴・集計・設定の切り替え）
4. 育児行動管理
5. 育児ログ登録
6. ダッシュボード集計（日・週・月・全期間）
7. 記録履歴（タイムライン）
8. 称号獲得（累計回数・連続日数の両方式）
9. X投稿文生成・コピー
10. 設定画面（ハブ：プロフィール編集・ログアウト＋各機能への入口）

### Phase 2（自分の詳細分析／他の父親の傾向を見る／育児の節目）

- **ユーザー独自の育児行動管理（カスタム育児行動）**（作成・削除、上限8個。[screens.md](screens.md) S14）
- **日別育児タイムラインチャート**（横軸：時間帯・縦軸：回数。`occurred_at` の時刻を活用）
- 全体タスク傾向（**タスク種別ランキング表示**＋設定からの導線）
- 年代別タスク傾向
- 子ども年齢帯（末子）別傾向
- 卒業＆エンドロール
- 称号一覧（図鑑）画面（獲得済みの一覧＋「次の称号」だけを進捗％付きで表示）

> 傾向集計で並べるのは“育児タスクの種類”のみ。個人ランキング・県別ランキング・母親との比較は行いません（[concept.md](concept.md) §3.3）。

### Phase 3（使い勝手の向上・継続支援）

- PWA 化
- 称号獲得通知
- 放置リマインド通知（母親バージョン）
- 頑張りすぎアラート（父親バージョン）

### 将来案

- LINE 共有（外部連携・後回し）
- 広告（設定画面のみ）
- AI 要約（孫ニュース）
- NativePHP モバイル版（API クライアントとして）
- アカウント削除（退会。問い合わせ対応、Phase 2以降で検討）

### 育児行動一覧（基本8個の選定候補プール）

> **選定方針（重要）**
>
> - 下の表は **候補プール** です。**項目はすべて暫定** であり、確定ではありません。HP は不採用（廃案。[decisions.md](decisions.md) §1.6）。
> - 対象は **「父親が意思を持って行う育児行動」のみ**。子どもの状態・行動が引き金になる育児行動は除外（詳細は [decisions.md](decisions.md) 設計原則）。
> - **UIアーキテクチャ確定**：常時表示は **4列×2段の8アイコン固定**。中身はユーザーが自由にピン留めでき、それ以外は「その他」ボタン→別画面（S4）からアクセスする（[decisions.md](decisions.md) §1.3）。
> - 登録時は共通のおすすめ8個で自動初期化。**具体的にどの8個にするか**は **実際に育児をして必要と感じたもの** から（机上では確定しない → [decisions.md](decisions.md) 未決#11）。ユーザーは登録後いつでも自由に入れ替え可能。

| 育児行動 | グループ案 | メモ |
| --- | --- | --- |
| おむつ交換 | 日常ケア | 頻度が高い。回数加算が効く |
| 着替え | 日常ケア | 嫌がると負荷増 |
| 歯磨き | 日常ケア | 嫌がりやすい |
| 鼻水ケア・鼻吸い | 日常ケア | 嫌がって暴れることあり |
| 爪切り | 日常ケア | 動くと難易度高 |
| 本の読み聞かせ | 日常ケア | 時間・集中力が必要。継続習慣になりやすい |
| ミルク・授乳補助 | 食事系 | 夜間は別途対応 |
| 遊び相手（室内） | 日常ケア | 短時間でも継続は地味に消耗 |
| お風呂 | 日常ケア | 沐浴期（新生児）を含む |
| 送迎（保育園・習い事等） | 外出・移動 | 時間拘束が大きい。朝の時間圧・帰り渋りなど変動 |
| 離乳食・食事補助 | 食事系 | 散らかし対応込み |
| トイレ補助・トイトレ | 日常ケア | 失敗対応で変動 |
| 散歩・公園遊び | 外出・移動 | 見守り＋安全確保 |
| 寝かしつけ | 対応・耐久 | 時間が読めない |
| 外出中の抱っこ | 対応・耐久 | 物理負荷が大きい |
| 発熱・看病・通院 | 対応・耐久 | 精神的負荷も大きい。待ち時間＋ぐずり対応込み（通院を含む） |
| 夜泣き対応 | 対応・耐久 | 睡眠不足で翌日にも影響 |
