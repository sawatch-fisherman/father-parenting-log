# TotoOps MVP 画面詳細レイアウト（ワイヤーフレーム）

> 本ドキュメントは、[screens.md](screens.md) で確定した画面一覧（S1〜S13）・ルーティング・Controller構成を前提に、**各画面内のコントロール配置（ボタン・入力欄・タブなど）のみ**を決めるものです。色・余白・フォント・アイコン意匠などの視覚デザインは対象外です。
>
> 4×2アイコングリッド（S3・S9）／期間タブ＋集計（S12）／日付グループのタイムライン（S13）は、参考として類似アプリ（Studyplus）のスクリーンショットを参照して構成しています（参考画像はローカル専用ファイルのためリポジトリには含めていません）。

## 記法凡例

| 記法 | 意味 |
|---|---|
| `[ボタン]` | ボタン |
| `(入力欄)` | テキスト入力 |
| `<セレクト ▾>` | ドロップダウン／セレクト |
| `《タブA｜タブB》` | タブ切り替え |
| `┌─┐│└─┘` | カード／グリッドの枠線 |
| `…` | ケバブメニュー（その他操作） |
| `>` | タップで詳細・次画面へ遷移することを示す行末記号 |


- 8枠のうち1つをタップすると、下記の入れ替えモーダルが開く。`[⇄]`のような小さい操作アイコンは置かない（スロット全体を大きいタップ領域にすることで誤タップを防ぐ。S3のグリッド設計と同じ考え方）。

- 保存でS7へ戻る。

## S14 カスタムイベント管理画面（Phase 2）

> MVP対象外（Phase 2）。ただし画面としての重要度が高いため、実装時期に先立ってレイアウトのみ確定しておく。ルーティング・Controller構成は[screens.md](screens.md)「Phase 2以降の画面（仕様検討中）」を参照。

### 通常時（8個未満）

```text
┌─────────────────────────────┐
│ [← 戻る]  カスタムイベント管理 │
├─────────────────────────────┤
│  登録数：5 / 8               │
│                             │
│  追加する                    │
│ (新しいイベント名          ) [追加]│
│                             │

│  寝返り練習の見守り     [削除] │
```

### 削除確認モーダル

```text
┌─────────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│  ┌───────────────────────┐  │
│  │ ⚠ 削除の確認            │  │
│  │                       │  │
│  │「ベビーマッサージ」を    │  │
│  │ 削除しますか？          │  │
│  │                       │  │
│  │ このイベントで記録した   │  │
│  │ 過去の育児ログもすべて   │  │
│  │ 削除されます。          │  │
│  │                       │  │
│  │ [キャンセル] [ 削除する ]│  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

- `[削除]`タップ時に表示。削除は物理削除で、紐づく`care_events`も`ON DELETE CASCADE`で道連れに削除されるため、実行前に必ずこの警告を経由する（decisions.md §1.3）。「キャンセル」で何もせず一覧に戻る。
